# Changelog

All notable changes to this project are documented in this file.

## 1.0.0 - 2026-10-28

- Add automatic discovery of connectable RAWv2 RuuviTags.
- Add live Bluetooth temperature, humidity, pressure, acceleration, movement, battery, and RSSI entities.
- Add event-driven GATT history synchronization at startup, after reconnection, and on manual request.
- Backfill missing Recorder states and statistics for temperature, humidity, and valid pressure samples.
- Preserve genuine archive gaps and existing live measurements.
- Add English and French translations.
- Add local Ruuvi branding and HACS packaging.
